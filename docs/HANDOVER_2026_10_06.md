## 1. Get running on the new machine

```bash
git clone https://github.com/NevixAA/wowza-betting.git     # or pull if it exists
cd wowza-betting
python -m venv .venv && .venv/Scripts/pip install -r requirements.txt
PYTHONPATH=. .venv/Scripts/python -m pytest tests/ -q      # expect 273 passed, 20 skipped
```

**`.env` does NOT travel — it is gitignored and that is correct.** Recreate it with the keys
this estate uses (`ODDS_API_KEY`, `APIFOOTBALL_KEY`, Telegram, and `CLOUDBET_API_KEY` if you
want to probe Cloudbet). `config.py` loads `.env` and `.api_keys` automatically. Never put a key
on a command line — it lands in shell history.

Shared data lives in the PARENT folder (`DATA_DIR = BASE_DIR.parent`), so clone into the same
`mixed/` layout or `England_Leagues_4_Seasons_With_Summary.xlsx`, `sofascore_cache.json` and
`best_params.json` will not be found.

### The big discovery: the gates were frozen for five weeks

`backtest_matrix.yml` ran the full xG enrichment with **no `actions/cache`**, so every job
started cold. On 2026-10-01 **all five jobs exceeded the 120-minute cap** and were cancelled.
The Sep 1 run predates the enrichment (wired in 2026-09-05) and finished in 1h 40m.

Consequence: `best_params_standard.json` and `backtest_results_standard.csv` frozen at
2026-09-01; `_LEAGUE_SNIPER_CALIBRATED` at 2026-06-04. Meanwhile the model gained xG (09-05),
37,623 previously-unserved cached rows (09-22), four restored seasons (09-23), +24,190 fixtures
(09-24). **The thresholds deciding which bets fire were fitted for a model that no longer
exists** — and the +24,190 fixtures that improved it are part of what pushed the backtest past
its cap. The improvement froze its own gates. Nothing reported it because a timed-out matrix
shows as a **grey partial**, not a red failure.

Same defect found in `backtest.yml` and `preseason_retrain.yml` by the test written for it —
five instances estate-wide, three previously unknown. All now cached; a parametrised test fails
CI if a sixth appears.

## 6. Open decisions that are yours

1. **League One / League Two** — same evidence profile MLS had. Paper-only or leave?
2. **`LEAGUE_SNIPER_CAP=0.12`** — it flattens every calibrated threshold to one number. At
   calibrated bars the standard track would have bet **10 times in 8 weeks instead of 264**, for
   −2.38u instead of −47.37u. Volume vs selectivity; genuinely a judgement call, and it should
   be re-measured once the fresh backtest lands.
3. **Cloudbet staking** — 4.5% is set, but 20 bets × 4.5% is 90% of bankroll in a day. The
   30% daily exposure cap currently binds at ~6 bets. Pick one or the other.
4. **v9 vs Pro duplication** — Pro already holds `book_odds_snapshots` with the same shape as
   v9's new `book_quotes`. Two stores, one purpose; they will drift.
