Status vocabulary:

| Status | Meaning |
|---|---|
| **DEPRECATED / PRODUCTION_REFERENCE** | Superseded in design, but still what serves. Removal needs an owner-approved cutover. |
| **DEPRECATED** | Not used for decisions; still present in the tree. |
| **LEGACY_RESEARCH** | A research family that keeps accruing but receives no new registrations. |
| **NOT_CERTIFIABLE** | Data that must never be used as evidence for a decision. |
| **REMOVED** | Gone from code; only provenance references remain. |
| **REPLACED** | A storage layout or mechanism swapped for a new one; the old form no longer exists. |
| **DORMANT** | Code that runs but can never produce anything. |
